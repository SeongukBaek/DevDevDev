기능 테스트: 사용자 입장에서 시스템이 제공하는 기능이 올바르게 동작하는지 확인, E2E(End to End) 테스트라고도 한다.
- 사용자가 사용하는 웹 브라우저나 모바일 앱부터, DB나 외부 서비스에 이르기까지 모든 구성 요소를 하나로 엮어서 진행
- 테스트 환경 제공이 어렵고, 시간이 오래 걸린다.

통합 테스트: 시스템의 각 구성 요소가 올바르게 연동되는지 확인.
- 소프트웨어의 코드를 테스트, DB 연결, 소켓 통신, 스프링 컨테이너 초기화와 같은 과정이 필요
- 이 또한 기능 테스트만큼은 아니지만, 테스트 환경 구성에 시간이 걸린다.

단위 테스트: 가장 작은 단위의 테스트로, 개별 코드나 컴포넌트에 대해 확인.
- 테스트 환경 구성이 비교적 쉽고, 오래 걸리지 않는다.

> 다양한 예외 상황에 대한 테스트는 주로 단위 테스트로 작성해서 확인하고, 주된 기능에 대해서는 기능 테스트나 통합 테스트로 확인한다.

외부 연동이 필요한 통합 테스트의 경우,
- DB 연동: 테스트 코드 내에서 DB를 조작. 미리 데이터를 인입해둘 수도 있고, 임의로 데이터를 삭제한 후 테스트할 수도 있다.
- HTTP 연동: WireMock을 사용해, 외부 서버를 스텁으로 대체한다.
